# Infocom Implementation Dashboard

Внутренний веб-модуль «Панель управления внедрением ИС» (Internal Implementation Dashboard).

---

## О проекте

MVP предназначен для агрегации статусов проектов внедрения информационных систем, фиксации блокеров и автоматизации сбора еженедельных отчётов от аналитиков.

**Заказчик:** Департамент проектного внедрения ООО «Инфоком-С» (г. Ставрополь).


---

## Технологический стек

- **Backend:** FastAPI / Django / .NET Core (на выбор)
- **Frontend:** React / Vue
- **БД:** PostgreSQL
- **Контейнеризация:** Docker, Docker Compose
